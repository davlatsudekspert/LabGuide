Ilovada ochish · Открыть в приложении · Open in app

Guruhga qo‘shilish

  1. Telefoningizda LabGuide o‘rnatilgan bo‘lsa — yuqoridagi Ilovada ochish tugmasini bosing: kod ilovaga o‘zi tushadi, kirgach taxallusingizni yozasiz va ustoz bergan test ochiladi.
  2. Tugma ishlamasa: LabGuide ilovasida O‘rganish → Guruh va topshiriqlar → Kod bilan qo‘shilish ni oching va yuqoridagi kodni kiriting (yoki shu sahifa havolasini nusxalab, Havolani qo‘yish ni bosing).
  3. Ilova hali yo‘q bo‘lsa — App Store yoki Google Play’da LabGuide ni qidiring.

Kod faqat guruhga qo‘shilish uchun. Guruhda ustoz faqat taxallusingizni va topshiriq natijalaringizni ko‘radi; boshqa talabalar sizni ko‘rmaydi.

Вступить в группу

  1. Если LabGuide уже установлен — нажмите Открыть в приложении выше: код подставится сам, после входа введите псевдоним, и откроется тест от преподавателя.
  2. Если кнопка не сработала: в приложении LabGuide откройте Обучение → Группы и задания → Вступить по коду и введите код выше (или скопируйте ссылку этой страницы и нажмите Вставить ссылку).
  3. Если приложения ещё нет — найдите LabGuide в App Store или Google Play.

Код нужен только для вступления в группу. Преподаватель видит только ваш псевдоним и результаты заданий; другие студенты вас не видят.

Join a group

  1. If LabGuide is installed, tap Open in app above: the code fills in by itself, you sign in, type a nickname, and your teacher’s test opens.
  2. If the button does not work: in the LabGuide app open Learn → Groups and assignments → Join with a code and enter the code above (or copy this page’s link and tap Paste link).
  3. No app yet? Search for LabGuide in the App Store or Google Play.

The code is only for joining the group. The teacher sees only your nickname and assignment results; other students do not see you.
