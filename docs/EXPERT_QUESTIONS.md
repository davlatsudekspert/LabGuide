# Mutaxassis aniqlashtirishi kerak bo'lgan savollar (2026-10-09)

Barcha kontent `draft`. "Agent tekshiruvi" (manbaga solishtirish) mustaqil mutaxassis
tasdig'i emas. Quyidagilar faqat mutaxassis (ustoz / gematolog / klinik biokimyogar)
hal qila oladigan savollar.

## Toifa imtihoni (KDL, rasmiy ro'yxat)
1. **Og'zaki 093** (mochevina usuli, ureaza tafsiloti): javoblar faylidagi xato tuzatishi
   uchun ochiq manba topilmadi — ilovada "Manba kerak" belgisi bilan, baholanmaydi.
2. **Og'zaki 283** "Teri disbiozining namoyon bo'lish variantlari": "teri" yoki "qin"
   (ro'yxatda yonida "Qin disbakteriozi" bor). Aniqlashtirilguncha baholanmaydi.
3. **Og'zaki 243** "apo-V, apo-A": apo-B (kirill "апо-В") yoki apoA-V nazarda tutilganmi;
   Lp(a) kutiladimi.
4. **Og'zaki 207** "O'rta molekulyar peptidlar": qaysi mahalliy metodika va me'yorlar
   kutiladi (xalqaro standart yo'q).
5. **Kalitsiz 8 ta test savoli** (ro'yxatda belgilanmagan): 194, 266, 290, 318, 365, 395,
   453, 477 — rasmiy kalit kerak; hozir testga kirmaydi.
6. **Bahsli/noaniq kalitlar** (34 + 46): ilovada "Rasmiy kalit" va "LabGuide izohi"
   ikkalasi ko'rsatiladi; ro'yxat: `tests_report.md` (koordinator scratchpad'idan

7. **Rasmiy imtihon vaqti va o'tish bali**; test banki toifalar bo'yicha bo'linadimi.
