# Mutaxassislik bo‘yicha ekspert paketlari (2026-10-25)

Har paket — o‘z mutaxassisi uchun CSV (ekspert to‘ldiradigan ustunlar bilan). Hammasi `HOLD_EXPERT`: ilovada **ko‘rsatilmaydi**; ekspert imzosisiz chiqmaydi (guard test). Bo‘yoq va kattalashtirish faqat Commons tavsifida yozilgan bo‘lsa ko‘rsatiladi, aks holda "ko‘rsatilmagan" (taxmin qilinmaydi). Paket PDF’lari (kichraytirilgan nusxalar bilan) hisobot ZIP’ida.
